# Academic Evaluation and Benchmarking Suite

This directory contains evaluation datasets, benchmarking scripts, and latency profiling tools for the final-year engineering project.

## Planned Evaluation Dimensions
1. **End-to-End Latency**: Time from shutter trigger $\to$ VLM scene description $\to$ TTS audio playback.
2. **Spatial Accuracy**: Correctness of relative object locations (*"left"*, *"right"*, *"in front"*).
3. **Linguistic Quality**: Fluency and naturalness of English and Telugu generated descriptions.
4. **Accessibility Usability**: Response times and task completion metrics with visually impaired / blindfolded users.

*Detailed benchmarks and test datasets will be populated during the AI perception integration phase.*
